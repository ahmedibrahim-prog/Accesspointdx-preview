Chemistry

BMP, CMP, Lipid Matrix // CPT 80048
Tube Designation: Gold SST (Tiger/Gold Top)
✓ Clot Time: Allow blood to clot vertically for 30 minutes before centrifugation.
✓ Centrifugation Parameters: Spin down at 3,000 RPM for 10 minutes.
✓ Processing Window: Transfer isolated serum within 2 hours post-draw.

Hematology

CBC, QuantiFERON // CPT 85025
Tube Designation: Lavender EDTA
✓ Inversion Rate: Mix gently by inversion 8–10 times immediately post-collection.
✓ Centrifugation: Do NOT spin whole blood hematology specimens.
✓ QuantiFERON Mandate: Incubate whole blood matrix at 37°C within 16 hours of collection.

Molecular

Respiratory, STI Panels // CPT 87635
Collection Kit: Synthetic VTM Swab Kit
✓ Collection Matrix: Use synthetic Dacron or Rayon tipped swabs only.
✓ Shaft Integrity: Plastic shafts required. Wood stems contain PCR inhibitors.
✓ Cold Chain Window: Transport refrigerated to preserve nucleic acid target markers.

Toxicology

Medication Compliance Logs // CPT 80307
Collection Kit: Thermal Collection Cup Kit
✓ Thermal Window Validation: Internal temp strip must read 32°C–38°C within 4 minutes.
✓ Security Protocol: Secure tamper-evident adhesive labels immediately upon collection.
✓ Stability Thresholds: Ambient: 7 Days // Refrigerated: 14 Days max.
